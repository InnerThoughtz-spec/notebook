5 · TURN relay (needed for restrictive networks)

WebRTC needs a TURN relay when direct UDP is blocked (school/work WiFi, restrictive mobile carriers). The default public TURN (openrelay.metered.ca) is often blocked or rate-limited. Best free option: Cloudflare Realtime TURN — free account, 1 TB/month, very fast. After signup, go to Realtime → TURN → create credentials, paste here:

Cloudflare Realtime credentials expire every 24h. Instead of pasting fresh ones daily, give the launcher your master Token ID + API Token (created at dash.cloudflare.com → Realtime → TURN). It will auto-mint a new 24h credential whenever the current one is about to expire.

7 · Streaming backend (Sunshine vs Apollo)

Sunshine is the original open-source GameStream host. Apollo is a Sunshine fork with extra features: per-client app isolation, WGC capture (works for fullscreen-exclusive games that DXGI can't capture), updated virtual display driver. Both speak the same protocol — your Moonlight clients work with either.

Only one can run at a time (they share ports 47984/47989/47990/47999). Switching requires admin (server must be running elevated).
